# Assignment 3: Cell Motility

Contains code and figures corresponding to the third assignment about the Rac-Rho
reaction model for cell motility. The dimensionless model is studied as a function of
the parameter B: its equilibria, their stability, and the different routes by which the
cell can "tip" from one polarisation state to another (bifurcation-induced and
rate-induced tipping).

## code

### Requirements

Install python and pip. Use pip to install the libraries listed in `requirements.txt`
(numpy and matplotlib), e.g. `pip install -r requirements.txt`.

### main.py

The control panel of the assignment. It imports the model and solvers from the files
below and runs one (or a few) functions per exercise, producing every figure of the
report. All parameters live in the `main` block at the bottom, so
only values change there while the methods stay in their original files.

Run it directly with command: `python3 main.py`. The figures are written to `../figures` via
`save_house`, and the interactive windows pop up at the end through `st.show()`. The
exercises are laid out in order:

- **Q1** — integrates one trajectory and overlays it on the continuation diagram
  (`plot_trajectories`), saving figure1.
- **Q2** — domains of attraction at B = 0.03: equilibria are pulled off the continuation
  branch, classified, and the basins are mapped over a grid of initial conditions while
  the saddle's stable/unstable manifolds are traced (`basin_map`, `trace_manifold`,
  `plot_basins`), saving figure2.
- **Q3** — a drifting B (dB/dt = eps). One continuation feeds both the drift trajectories
  (figure3) and the critical-slowing-down analysis: measured recovery rate vs theory
  (figure4) and state perturbations along the drift in rho and Rac (figure5, figure6).
- **Q4** — rate-induced tipping with a saturating B (dB/dt = eps*(Bmax-B)/Bmax). The
  critical rate is bisected (`critical_rate`) and shown as an R-tipping diagram (figure7)
  and as sub- vs super-critical drift trajectories (figure8).

### continuation.py

Holds the model itself and the continuation routine. The right-hand sides are `fun` (the
2D Rac-Rho system at fixed B), `fun_ext` (B appended as a third state with the linear
drift dB/dt = eps, used in Q3) and `fun_ext_sat` (the saturating drift used in Q4),
together with the analytical Jacobians `jac` (w.r.t. the state) and `jac_B` (w.r.t. B).

`run_continuation(params, B0, Bmax, ds)` traces the equilibrium branch of the (Rac, rho)
system as B varies using a standard pseudo-arclength predictor-corrector scheme: an Euler
predictor along the tangent followed by a Newton corrector with an arclength constraint.
It returns the branch, the stable/unstable splits (from the sign of the largest
eigenvalue) and the eigenvalues used to assess stability. Running this file directly
reproduces the reference Figure 1.

### rootfinding.py

The Newton solvers used throughout. `newton` solves the extended system (state plus
parameter) subject to the arclength equation and is the corrector of the continuation
routine; `newton_small` solves the plain 2D system at a fixed B, used to locate and
refine individual equilibria. Iteration diagnostics are emitted through a module logger
(silent by default; enable with `logging.basicConfig(level=logging.DEBUG)`).

### timeintegrator.py

A fixed-step fourth-order Runge-Kutta integrator, `time_integrator(modelfun, params, x0,
dt, T)`. It returns the time array and the state history; in `main.py` it is wrapped by
`integrate_trajectory` so the same routine drives both the linear (Q3) and the saturating
(Q4) drift laws.

## plottingtools

A small styling/output package provided with the assignment. `configure` sets up the
house plotting style and colour cycle, `show` displays the figures and optionally saves
them at the configured resolution, and `step_config` holds the shared style settings.

## figures

The output PNGs (figure1 ... figure8) generated by `main.py`, one or two per exercise as
listed above. The current code may need adapting to suit the needs of the user.
