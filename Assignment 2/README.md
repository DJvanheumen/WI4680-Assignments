# Assignment 2: A Simple Model For Cancer Growth

Here the code and figures are provided for the second assignment. Modeling cancer growth as a logistic model between three species: tumor, healthy tissue and immune cells. The goal is to study linear stability near the different equilibrium points. First a simple rootfinding method is implemented using explicit Jacobian J(p) for parameter vector p. Then a continuation routine is implemented to find a Hopf bifurcation. A shooting method is implemented to find periodic solutions. Period doubling bifurcations occur.
